# МЕБЕЛЬКА35 — сайт-каталог мягких кроватей

**Независимая демонстрационная версия**, созданная для предложения производителю «Мебелька35» из Вологды. Не является действующим официальным магазином.

## Быстрый просмотр

Распакуйте архив и откройте `preview-offline.html` в браузере. Он содержит встроенные стили, изображения и скрипты; главная страница работает без локального сервера. Для просмотра отдельных страниц в автономном формате откройте соответствующий файл `preview-catalog-offline.html`, `preview-materials-offline.html`, `preview-designer-offline.html` или `preview-contacts-offline.html`.

Для проверки **переходов между страницами** размещайте сайт на Vercel или используйте локальный HTTP-сервер. Пример: находясь в корне папки проекта, выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`.

## Публикация на Vercel

1. Загрузите содержимое папки в репозиторий GitHub, чтобы `index.html` находился в корне.
2. В Vercel откройте **Add New → Project**, импортируйте репозиторий.
3. Выберите **Framework Preset: Other**; команды сборки и Output Directory не нужны.
4. Нажмите **Deploy**. Сайт полностью статический (HTML, CSS, JavaScript, SVG).
5. Подставьте опубликованный адрес в файл `СООБЩЕНИЕ_ДЛЯ_VK.txt` и свяжитесь с владельцем.

## Структура

- `index.html` — главная с коллекцией и подбором оттенков.
- `catalog.html` — 8 демонстрационных концепций, категории и фильтры по размерам, переключение цвета, подробные карточки.
- `materials.html` — демонстрационная палитра шести оттенков и блок рекомендаций по тканям.
- `designer.html` — визуальный конструктор (6 форм изголовья, 6 оттенков, размеры, ткань, дополнительные опции, текст заявки, предпросмотр до 3 фотографий).
- `contacts.html` — связи с мастерской и предупреждение о необходимости уточнить адрес.
- `assets/style.css` — стили и адаптивная верстка.
- `assets/app.js` — навигация, фильтры, карточки, конструктор, локальные фотографии и копирование заявки.
- `assets/data.js` — данные демонстрационных концепций и названий цветов.
- `assets/scenes/` — 49 оригинальных векторных интерьеров SVG (48 вариантов комбинаций + hero).
- `previews/` — скриншоты, результаты проверки адаптивности `qa.json`.
